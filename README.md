# pairwise-grass-instancing

草原在远处变成一片闪烁的噪点，草叶用 alpha 测试但没开 mip 偏置，远处采样到最高层细节；实例剔除只在 CPU 按包围盒做，相机转动后整片草突然消失；风吹动顶点在顶点着色器里算，阴影 pass 用的是另一套相位，影子与草叶错位；LOD 切换按实例距离硬切，同一丛草一半高模一半公告板；公告板朝向没跟随相机，侧看时草片变成一条线；密度图与地形 splat 不同步，石头区域也长满草；GPU 剔除结果回读到 CPU 晚两帧，被剔除的实例又画了一次；透明裁剪的 alpha 阈值随距离变，远处草叶越来越细直到消失；实例数据按 16bit 存位置，大世界坐标精度不足，草叶抖动；阴影投射只画近处 LOD，远处草地没有影子，明暗断层。render/grass_instancing.py 是核心，tests/test_grass_instancing.py 15个红。要修的是：alpha 测试加 mip 偏置；剔除按视锥与遮挡；风相位跨 pass 一致；LOD 交叉淡化；公告板朝相机；密度与 splat 对齐；剔除结果双缓冲；alpha 阈值按覆盖率；实例位置局部化；阴影 LOD 独立。

## 运行

```bash
python -m pytest tests -q
```

初始状态：15 个用例失败。修复实现使全部用例通过，不要修改 `tests/` 下的测试。
